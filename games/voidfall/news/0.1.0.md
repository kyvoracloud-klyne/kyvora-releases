# Project Voidfall 0.1.0

First playtest build served through the Kyvora Games Launcher. This is a technical
playtest rather than a balance pass, so expect rough edges and tell us about them.

## What is in it

- Four characters, each with an ability and a starting weapon
- Procedurally generated layers from a shared seed, with portals between them
- Cooperative play for up to four players over LAN, host-authoritative
- Cover, crouch and line-of-sight combat against ten enemy archetypes
- Grid inventory, searchable containers, loot, extraction and progression
- Pause menu with rebindable controls, accessibility and graphics tiers

## Known rough edges

- No audio assets yet beyond generated cues
- Which graphics tier holds 60 FPS is still an open question; `high` is the default
  and `medium` drops fog and shadows if it stutters
- Windows will warn on first run because the build is not code signed
