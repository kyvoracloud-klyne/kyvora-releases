# Project Voidfall 0.1.0

The first build delivered through the Kyvora Games Launcher. Updates from here on arrive as patches:
the launcher compares a checksum per file and downloads only what changed, so a balance pass costs
kilobytes rather than a reinstall.

## What is in this build

- Top-down orthographic 3D presentation, procedurally posed characters and authored dungeon kit meshes
- Cover, crouch and line of sight as one model: a shot is a sloped segment that either clears a height
  or runs into it
- Enemy tactics by archetype, with abilities for melee cleave, cloak and the Devout's charge
- Grid inventory, searchable containers and the pause menu with accessibility and keybinding panels

## Notes

- Saves live beside the game and are never touched by an update.
- If a download is interrupted, reopening the launcher resumes it rather than starting again.

> Something wrong with an install? **Settings -> Verify files** rehashes everything against the
> manifest and repairs only what does not match.
